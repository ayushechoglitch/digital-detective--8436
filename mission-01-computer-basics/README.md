# Mission 01 — Know your computer

## 1. Mission title
Mission 01 — Know your computer.

## 2. Task / objective
Explain how a computer receives input, processes data, produces output and stores information (IPOS). Identify hardware, software and everyday computer-based systems.

## 3. Work completed
### Task 1.1 — IPOS example: typing and saving a document

| Stage | What happens | Hardware / component |
|---|---|---|
| Input | I press keys and enter text into a document. | Keyboard |
| Processing | The application receives the keystrokes and the processor executes its instructions; memory holds the active work. | CPU and RAM |
| Output | The document and typed text appear on the display. | Monitor / screen |
| Storage | When I save, the document is written to a storage device or selected cloud location. | SSD / cloud storage |

The keyboard sends input to the computer. The CPU and memory help process it. The screen shows the result, and saving stores the document so it can be opened later.

## 5. My understanding
IPOS describes the basic information flow in a computer. Hardware is the physical equipment, while software is the set of instructions that tells the hardware what to do. Operating-system software manages resources, application software helps users complete tasks, and utility software helps maintain or inspect the system.
