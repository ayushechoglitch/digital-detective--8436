## About This Project
Digital Detective is a hands-on exploration assignment designed to bridge foundational computer science concepts with practical daily engineering workflows. Throughout this project, I investigated how hardware and software collaborate, navigated the Terminal command line, inspected operating system processes and resource limits, evaluated program execution models, converted different numbering systems, and analyzed how information travels across networks and the internet.

Every mission is isolated in its own dedicated directory with relevant explanations, verified observations, and sanitized evidence records.

## Core Topics Covered
- **The IPOS Cycle:** Input, Processing, Output, and Storage hardware roles.
- **Software Hierarchy:** Firmware, operating system services, user-space applications, and diagnostic utilities.
- **Command-Line Proficiency:** Directory navigation, safe file creation/backup, piping (`|`), and standard streams redirection (`>`, `>>`).
- **OS Internals:** Process lifecycle, memory utilization, relative vs absolute paths, and POSIX permissions (`rwxr-xr-x`).
- **Execution Paradigms:** Ahead-of-time (AOT) compilation versus runtime interpretation and Python bytecode (`.pyc`).
- **Data Encoding & Arithmetic:** Manual radix conversions (decimal, binary, hexadecimal), character mapping (ASCII and UTF-8).
- **Version Control Mechanics:** Atomic commits, the staging index, branch isolation (`update-about`), and Pull Request reviews.
- **Internet Protocol Stack:** LAN vs WAN topologies, DNS resolution, packet switching, and the client-server request-response lifecycle.

## Running the Number Converter
A Python-based radix converter is included in Mission 05. To test it from the repository root:

```bash
python3 mission-05-numbers-data/number_converter.py
```

Enter any positive decimal integer when prompted to see its formatted binary (`0b...`) and hexadecimal (`0x...`) equivalents.
